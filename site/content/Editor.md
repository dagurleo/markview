# Editor

Press ⌘U and the Markdown opens in an editor beside the page. The page follows a moment after you stop typing, and the two scroll together. Documents always open as pages to read; File > New (⌘N) starts one with the editor open.

You can try it on this site: press Edit at the top, or ⌘U, and change any page. Nothing you write here is saved.

- Nothing is written until you save (⌘S). Unsaved edits are kept aside every few seconds, and come back after a crash.
- Headings, emphasis, links and lists are coloured as you type, and code blocks by their language.
- Return carries a list or a quote on to the next line, and Tab nests a list item under the one above.
- Type `/` at the start of a line or after a space for a menu of things to insert: headings, lists, code blocks, tables, links, pictures, maths, diagrams, callouts, footnotes and front matter. Typing narrows it, so `/swift` gives a Swift code block.
- In a table, Tab and ⇧Tab go from cell to cell and keep the columns lined up, and Return adds a row.
- Paste a web address over selected text to make it a link. Drop a picture on the editor to put it in, or any other file to link to it.
- Double-click a block on the page to go to where it is written.
- If another app changes the file while you have unsaved edits, a bar above the editor asks which to keep.

Settings > Editor chooses the font, line numbers, wrapping, what Tab inserts, spelling, and whether `/` opens the menu.
