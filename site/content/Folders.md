# Folders

Open a folder with File > Open…, the `markview` command, or by dropping it on Markview's Dock icon or a window. The window starts at the folder's README and lists its Markdown files in the sidebar, keeping up as files come and go.

![A project folder in Markview, in the Rosé Pine theme](/shots/folder-light.webp#gh-light-mode-only)
![A project folder in Markview, in the Rosé Pine theme](/shots/folder-dark.webp#gh-dark-mode-only)

- A link to another Markdown file opens in the same window, and ⌘-click opens it in a new one.
- Go > Back (⌘[) and Forward (⌘]), or a mouse's side buttons, return to the exact place you left.
- The Contents tab lists the headings and marks the one you are reading. View > Show Sidebar (⌃⌘S) shows it for a single file too.
- Hidden folders and `node_modules` are left out.

This site works the same way: the sidebar is its folder, and your browser's Back and Forward return to where you were.
