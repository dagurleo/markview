# Incident runbook

> [!IMPORTANT]
> Acknowledge the page within **five minutes**, even if all you say is "looking".

## First ten minutes

1. Open the site yourself. Is it down for you too?
2. Check the [status of the host](https://status.example.com).
3. Post in `#incidents` using the template below.

```text
🔴 example.com is down since 14:02 UTC
Owner: @you · Next update: 14:20
```

> [!WARNING]
> Don't restart the database to "see if it helps". Page the database owner instead.

## Afterwards

- [ ] Write the timeline while it's fresh
- [ ] Book a 30-minute review within the week
- [ ] File follow-ups with an owner each
